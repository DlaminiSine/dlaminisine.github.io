Building a clean data model from five content datasets

Python notebook  |  Data cleaning and modeling

The question

How can five separate tables about content, users, sessions, and reactions be combined into one clean dataset ready for analysis?

  1. 5 CSV files
  2. →
  3. Left joins: 25,573 rows
  4. →
  5. Drop empty columns and rows: 24,573 rows
  6. →
  7. Standardize 16 categories
  8. →
  9. Excel data model

What I did

  1. Loaded five CSV files: reactions, reaction types, content, user profiles, and sessions.
  2. Merged them into one table with a chain of left joins on the shared keys, giving 25,573 rows and 14 columns.
  3. Checked for missing values, dropped the columns that were mostly empty (URL, interests, and a duplicate user ID), and removed the remaining incomplete rows, leaving 24,573 rows.
  4. Standardized the content categories, which had inconsistent capitalization and stray quotation marks (for example, "studying" and "Studying"), down to 16 clean categories.
  5. Exported the final data model to Excel for analysis.
