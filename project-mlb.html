Predicting MLB home-game attendance

August 2026  |  Group practicum, team of 2  |  Essentials for Data Science (DS5110), Northeastern University

The question

How accurately can MLB home-game attendance be predicted from team, opponent, schedule timing, weather, and promotional events?

  1. Game records (CSV)
  2. +
  3. Weather (Open-Meteo API)
  4. +
  5. Promotion notes (text)

  7. Star-schema SQLite database
  8. →
  9. SQL reporting
  10. →
  11. Linear regression vs. KNN, nested cross-validation
  12. →
  13. RMSE, MAE, R²

What I did

  1. Integrated three data sources for five MLB teams: game records in CSV files, weather data from the Open-Meteo API, and promotional notes stored as unstructured text.
  2. Designed a star-schema SQLite database so the three sources could be joined consistently and queried with SQL.
  3. Wrote SQL reports on what drives turnout: which promotion types lift attendance, how promotions perform in adverse weather, which opponents draw, and how schedule characteristics such as weekend versus weekday, day versus night, and month affect attendance.
  4. Compared two predictive models, multiple linear regression and KNN regression, using nested cross-validation, and measured them with RMSE, MAE, and R².
  5. Delivered a reproducible R Markdown report that runs the whole analysis from the database to the model comparison. I completed it with one teammate.
