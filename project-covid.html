COVID-19 data exploration in SQL

Guided project  |  SQL

This is a guided project. I followed Alex the Analyst’s data analyst portfolio series (part 1) and worked through the queries myself.

The question

How did COVID-19 cases, deaths, and vaccinations compare across countries and continents, and how can the results be prepared for a dashboard?

  1. covid_deaths and covid_vaccinations tables
  2. →
  3. Filtering, joins, window functions
  4. →
  5. Views and queries ready for Tableau

What I did

  1. Explored two tables, covid_deaths and covid_vaccinations, and filtered out the rows that aggregate whole regions so each country is counted once.
  2. Calculated death percentage (total deaths as a share of total cases) and the share of each country’s population that got infected, over time.
  3. Ranked countries by highest infection rate and by total death count, then broke the results down by continent and by date for global totals.
  4. Joined deaths and vaccinations and used a window function to compute a rolling count of people vaccinated in each country, then saved it as a table and a view for later use.
  5. Wrote four queries to prepare data for Tableau visualizations: global totals, deaths by continent, infection rate by country, and infection rate by country over time.

Code preview

Rolling count of people vaccinated, by country

SELECT cd.continent, cd.location, cd.date, cd.population, cv.new_vaccinations,
       SUM(cv.new_vaccinations) OVER (PARTITION BY cd.location ORDER BY cd.location, cd.date) AS rolling_people_vaccinated
FROM covid_deaths cd
JOIN covid_vaccinations cv
  ON cd.location = cv.location
 AND cd.date = cv.date
WHERE cd.continent IS NOT NULL AND cd.continent != '';

Which countries have the highest infection rates?

SELECT location, population,
       MAX(total_cases) AS highest_infection_count,
       (MAX(total_cases)/population)*100 AS case_percentage
FROM covid_deaths cd
WHERE continent IS NOT NULL
GROUP BY location, population
ORDER BY case_percentage DESC;
