Hospital data analytics and relational database

July 2026  |  Group practicum, team of 2  |  Essentials for Data Science (DS5110), Northeastern University

The question

How can raw hospital XML data be turned into a clean, trustworthy database that supports multiple reporting requirements?

  1. XML data
  2. →
  3. Relational SQLite database
  4. →
  5. SQL joins, aggregations, validation rules
  6. →
  7. Data-quality checks
  8. →
  9. Report visualizations in R

What I did

  1. Integrated XML data into a relational SQLite database as part of an end-to-end hospital analytics solution, working with one teammate.
  2. Designed and queried the database with SQL joins, aggregations, and validation rules to produce accurate datasets for several reporting requirements.
  3. Ran data-quality checks in SQL to find missing, unknown, and incorrectly categorized records across the dataset, which improved the accuracy and transparency of the final analysis.
  4. Produced report visualizations in R from the validated data.
