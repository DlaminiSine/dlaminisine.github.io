Fantasy Premier League player performance

February 2026  |  Personal project

The data comes from the public vaastav Fantasy Premier League repository on GitHub.

The question

Which Fantasy Premier League players perform best by position and team, and what should a manager look at besides total points?

What I did

  1. Loaded two tables from the public vaastav Fantasy Premier League dataset into SQLite: cleaned_players (season-level player statistics) and merged_gw (gameweek-level data with position and team).
  2. Validated and cleaned the data: previewed both tables, counted records, found and removed a duplicate player entry, and checked key columns for nulls.
  3. Built a shared key by concatenating first and second names into a name column, so the two tables could be joined. I also found players that appeared in one table but not the other.
  4. Explored the data with aggregate queries: top scorers and assist providers, how many players share each points total, and the date range of the gameweek data.
  5. Compared players within their position: top five by points for goalkeepers, defenders, midfielders, and forwards, split by players who played every minute and those who did not, plus goals, assists, clean sheets, and goals conceded by position.
  6. Ranked players within each team with a window function to get the top three point scorers per club, and looked at the creativity, influence, and threat metrics.
  7. Turned the analysis into a Tableau dashboard of the 2022/23 season so a non-technical viewer can explore the results without reading any SQL.

Results

The main takeaway is that total points alone is an incomplete way to judge a player. A fuller assessment also looks at minutes played, position, goals and assists, clean sheets, and the creativity, influence, and threat scores. Players with high creativity or threat can be strong picks even when they are not yet the top scorers, and comparing players within their position and team gives more context than ranking everyone together.

Cleaning: find duplicates and build a join key

-- Find players that appear more than once
SELECT first_name, second_name, COUNT(*)
FROM cleaned_players
GROUP BY first_name, second_name
HAVING COUNT(*) > 1;

-- Create a name column to match the gameweek table
ALTER TABLE cleaned_players ADD name TEXT;

UPDATE cleaned_players
SET name = CONCAT(first_name, ' ', second_name);

Top three players in each team by total points

SELECT team, name, total_points
FROM (
    SELECT mg.team AS team,
           cp.name AS name,
           cp.total_points AS total_points,
           ROW_NUMBER() OVER (PARTITION BY mg.team ORDER BY cp.total_points DESC) AS player_rank
    FROM cleaned_players cp
    JOIN merged_gw mg ON mg.name = cp.name
    GROUP BY mg.team, cp.name, cp.total_points
) AS ranked_players
WHERE player_rank <= 3;
