Cyclistic bike-share analysis in SQL

Case study  |  SQL (PostgreSQL syntax) and Tableau

The question

How do casual riders and annual members use the bikes differently?

  1. 12 monthly trip tables, Oct 2021 to Sep 2022
  2. →
  3. One combined table (UNION ALL)
  4. →
  5. Cleaning and date fields
  6. →
  7. Views and member vs. casual comparisons
  8. →
  9. Top casual-rider stations with coordinates

What I did

  1. Combined twelve monthly trip tables (October 2021 to September 2022) into one table with UNION ALL.
  2. Calculated ride length in minutes and cleaned the data: I removed trips with missing or blank station names, and trips with zero, negative, or over-24-hour ride lengths.
  3. Created date fields for weekday, month, year, and ride date so rides could be grouped by time.
  4. Built reusable views for riders per day and average ride length by rider type, and split members and casual riders into temporary tables to compare average ride length by weekday, month, and year.
  5. Counted riders by month and weekday for each group, and pulled the top 20 start stations for casual riders with their coordinates so I could map them in Tableau.

Code preview

Cleaning: remove missing stations and invalid ride lengths

DELETE FROM cyclistics_bike_share_data
WHERE start_station_name IS NULL OR trim(start_station_name) = ''
   OR end_station_name IS NULL OR trim(end_station_name) = '';

DELETE FROM cyclistics_bike_share_data
WHERE ride_id IS NULL OR start_station_name IS NULL
   OR ride_length IS NULL OR ride_length <= 0;

-- Rides longer than a day (1,440 minutes)
DELETE FROM cyclistics_bike_share_data
WHERE ride_length > 1440;

Members vs. casual riders by day of the week

SELECT (CASE
          WHEN day_of_the_week = '0' THEN 'Sunday'
          WHEN day_of_the_week = '1' THEN 'Monday'
          -- ... and so on through Saturday
        END) AS day_name,
       COUNT(CASE WHEN membership_type = 'member' THEN 1 ELSE NULL END) AS number_of_member_riders,
       COUNT(CASE WHEN membership_type = 'casual' THEN 1 ELSE NULL END) AS number_of_casual_riders,
       COUNT(*) AS number_of_users
FROM cyclistics_bike_share_data
GROUP BY day_of_the_week
ORDER BY day_of_the_week;
