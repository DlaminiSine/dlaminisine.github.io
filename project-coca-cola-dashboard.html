Coca-Cola sales dashboard in Power BI

Power BI project

A screenshot of the dashboard appears on this page when the image file is added to the site.

The question

Which beverage brands and states drive sales and operating profit?

  1. Sales data
  2. →
  3. Map, brand table, key influencers
  4. →
  5. Date slicer and Q&A
  6. →
  7. Interactive Power BI dashboard

What I did

  1. Loaded a sales dataset with state, beverage brand, total sales, units sold, price per unit, operating profit, operating margin, and invoice date.
  2. Built a map of total sales by state, sized by sales.
  3. Built a table by brand showing total sales, units sold, price per unit, operating profit, and operating margin side by side.
  4. Added a key influencers visual to see which brands explain differences in operating profit, and a Q&A visual so viewers can ask questions in plain language.
  5. Added a date slicer so the whole dashboard can be filtered by invoice date.
