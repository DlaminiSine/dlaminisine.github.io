Nashville housing: data cleaning in Excel

Excel project  |  Data cleaning

The question

How can a messy raw property-sales dataset be cleaned and restructured so it can be analyzed by city, land use, and sale type?

  1. 56,477 raw records
  2. →
  3. Split addresses, clean columns
  4. →
  5. 16,710 clean records
  6. →
  7. Calculated columns
  8. →
  9. Pivot tables

What I did

  1. Started from the raw dataset of 56,477 property sales with 19 columns.
  2. Cleaned and restructured it into a table of 16,710 records, splitting the combined address text into separate street, city, and state columns for both properties and owners.
  3. Added calculated columns: total value (land plus building value) and a profit figure (sale price minus total value) using table formulas.
  4. Built pivot tables comparing the number of sales and the average sale price, land value, building value, and total value by city, by land use, and by whether the property was sold as vacant.

Results

  • Most sales were in Nashville itself (12,869 of 16,710), with an average sale price of $275,096.
  • Brentwood had the highest average sale price ($446,546 across 134 sales), while Antioch (1,148 sales) averaged $131,052.
  • Single-family homes made up 14,470 of the sales, at an average of $258,075.
  • The 292 properties sold as vacant averaged a $161,599 sale price.
